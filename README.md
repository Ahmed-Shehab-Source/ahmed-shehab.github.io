# Ahmed Shehab — Data Analyst & Business Intelligence Portfolio

A clean, modern, executive portfolio website tailored for **Ahmed Shehab** (Data Analyst | Business Intelligence Analyst | Data-Driven Decision Maker). Built with vanilla HTML5, modern CSS3 (custom design system, dark slate theme), and modular JavaScript.

## 🚀 Features
- **Executive Dark/Light Mode**: Smooth theme toggling with preferred system scheme persistence.
- **Dynamic Metrics & Case Studies**: Showcases key project achievements, business metrics (EGP 743K+ recoverable revenue, 100K+ orders, 528K FAERS records, 30-day forecasting), and technical stack details.
- **Interactive Competency Search**: Live search & filter across technical skills (Python, SQL, RAG, Power BI, Streamlit, MLOps, Docker, Airflow, n8n, etc.).
- **Categorized Project Filtering**: Filter projects by BI & Dashboards, Machine Learning & Analytics, or AI & Automation.
- **Professional Experience Timeline**: Comprehensive overview of internships at Telecom Egypt (WE), Pulse by Solutions (Giza Systems), and iSchool Egypt.
- **GitHub Pages Ready**: Zero build steps required; instant deployment via standard GitHub Pages or GitHub Actions.
